# 🚀 Test Github Repository

## 📌 Overview

This repository is created to explore and practice **Git and GitHub workflows**. It serves as a sandbox environment for understanding version control, collaboration, and project structuring.

Whether you're a beginner learning Git or an experienced developer testing features, this repo helps in building strong fundamentals.

---

## 🎯 Objectives

* Understand Git basics (init, add, commit, push)
* Learn branching and merging strategies
* Practice collaboration using pull requests
* Explore repository management features
* Maintain clean and structured code

---

## 🛠️ Tech Stack

* Git

## ⚙️ Getting Started

### 1️⃣ Clone the Repository

```
git clone https://github.com/your-username/test-github.git
```

### 2️⃣ Navigate to Project

```
cd test-github
```

### 3️⃣ Make Changes & Commit

```
git add .
git commit -m "Your message"
git push
```

---

## 🔄 Git Workflow

```
# Create new branch
git checkout -b feature-branch

# Work and commit
git add .
git commit -m "Added new feature"

# Push branch
git push origin feature-branch
```
